# Sahil Kadam — Data Analyst Portfolio

A responsive, premium-dark, static portfolio website for GitHub Pages.

## Files
- `index.html` — page content and project sections
- `style.css` — responsive dark/teal design
- `script.js` — mobile navigation toggle

## Before publishing
1. Open `index.html`.
2. Replace `YOUR_EMAIL@example.com` with your professional email.
3. Replace the LinkedIn and GitHub links with your profile URLs.
4. Add links to your actual project repositories or dashboard screenshots.
5. Check tool names, project descriptions, and skill statements for accuracy. Dashboard illustrations in this template are mockups, not real project results.

## Publish with GitHub Pages
1. Sign in at https://github.com/new.
2. Create a repository named `YOUR-USERNAME.github.io` for a user site. Choose **Public** on GitHub Free.
3. Upload all three files (`index.html`, `style.css`, `script.js`) to the repository root. You can drag and drop them into the repository using **Add file → Upload files**.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/(root)`, then click **Save**.
7. Wait for deployment, then visit `https://YOUR-USERNAME.github.io`.

GitHub says publishing can take up to around 10 minutes. Official guide: https://docs.github.com/en/pages/quickstart

## Important
GitHub Pages publishes static files publicly. Do not add passwords, API keys, private datasets, personal identification documents, or confidential employer data.
